# Changelog

Each release's section is what the GitHub Release says; keep it in plain words.

## Unreleased

- When a connection fails, Promptly now says what happened in plain words and what to try, such as "Nothing is answering on port 22: check the port number, and that the SSH server is running". The technical reason is still there under *Details*. A login the server refuses says which ways in it accepts, and an SSH agent that can't be used says why.
- A host set to *Password* now also signs in to servers that only ask for the password through their own login prompt (PAM). The saved or typed password answers that one question; any further questions, such as a two-factor code, are shown to you as usual.
- Setting a host's *Keep-alive* to 0 now really turns keep-alives off, as the host form says.
- Groups can set a default port and jump host as well as a user and key. Hosts left on port 22 use the group's port, and hosts without a jump host use the group's. A group inside another group takes the outer group's defaults for whatever it leaves blank. SFTP sync now reaches its server the same way a terminal session does, through the group's defaults and any jump hosts.
- Hosts have a *Tags* field, and the search box finds hosts by their tags and notes as well as their name and address.
- The host form has a *Test connection* button that runs the real connection steps with the form as it stands, without saving, and hangs up again. It shows what the group fills in: the user, the port, the key and the jump host.
- A host can be marked as production, with a label. Its sessions get a red bar across the top with the label in words, and on desktop its tabs carry the label too.
- The dot on a session turns amber and pulses while it reconnects, and says "Reconnecting…", instead of showing grey "Not connected". It stays steady when the system asks for less motion.
- Opening a group's settings no longer fails, and the hosts list header, host form and connection messages fit on a narrow phone with large text.
- The terminal bell does something now: the screen flashes briefly, or with reduced motion a thin outline shows instead. In Settings, Terminal, *Bell* can vibrate a phone instead, or be turned off.
- Settings, Terminal has *Lines to keep for scrolling back*: 1,000, 10,000 (as before), 50,000 or 100,000. It applies to sessions opened after the change.
- The text size is remembered: new sessions open at the size you last zoomed to, and *Text size* in Settings, Terminal sets it too.
- Curly, dotted, dashed and double underlines are drawn as such, in the colour the program asks for, so spell-check and error marks in editors look right.
- A full-screen program that starts redrawing and never says it has finished can no longer freeze the screen: after a moment Promptly shows what it has drawn.
- File paths and IP addresses in the output can be copied with Ctrl+click or from the right-click menu, as web links can be opened.
- Pasting text with more than one line shows it first, with how many lines it has, and offers *Paste*, *Paste without final newline* and *Cancel*, since each line runs as a command. It can be turned off in Settings, Terminal. Pasted text also loses any control characters, so a copied snippet can no longer slip commands past a program's paste protection.
- A server whose host key has changed now gets a full-page warning where *Disconnect* is the main button, and trusting the new key takes two deliberate steps. Once trusted, the new key replaces the old one everywhere, so the warning no longer comes back on every connect when the old key is still in `~/.ssh/known_hosts`. A server offering a different kind of key than the one trusted counts as changed, not as a new server, and Promptly asks servers for the kind of key it already trusts first. Hashed and `@revoked` lines in `~/.ssh/known_hosts` are understood, and one odd line no longer hides the rest of the file. Running snippets on many hosts and SFTP sync say plainly when a key has changed instead of suggesting you trust it.
- The engine now wipes the passwords, private keys, passphrases and vault keys it holds from its memory once it's done with them, and they never show up in its logs. (Copies held by the app's screens and by the libraries Promptly uses aren't covered.) A host's startup command no longer gets typed again into a persistent tmux session every time it reconnects (it runs once, when the tmux session is made), and two sessions to the same host with *Persistent session* on each get their own tmux session instead of mirroring one screen. The command-line tool no longer takes the passphrase or recovery code as an argument, where other people on the computer could see it; it asks, or reads an environment variable.
- Promptly can ask who's there. Before a key is used it asks for your fingerprint, face or device PIN (Windows Hello on Windows), and *Lock Promptly* in Settings, Security also asks when the app opens and when you come back to it. A check lasts 5 minutes by default, and that can be changed. On Linux, which has no such check for apps, you can set an app passcode instead.
- Removing a device now really cuts it off from sync. Everything it changes after it was removed is ignored by your other devices, and the next time it syncs it stops and tells you it was removed, keeping everything on it. To sync it again, disconnect it and join the vault again. Its part of the vault is tidied away once another device has kept everything in it.
- You can re-key the vault: it gets a new key, a new passphrase and a new recovery code, and a removed, lost or stolen device can read nothing written afterwards. Choose **Remove and re-key** when removing a device, or **Re-key** on the sync screen. Your other devices ask for the new passphrase once.
- Hosts and keys have a **Keep on this device only** switch. Turned on, the host or key (and its saved password or private key) never goes into the vault, and one that was already synced is removed from your other devices but kept here. Keys sync by default.
- When Promptly asks for a key's passphrase, **Remember passphrase** (on unless you turn it off) saves it with the key, encrypted like your other secrets. It syncs with the key, or stays on this device with a key kept on this device only. A saved passphrase is used for connecting, reconnecting, running snippets on many hosts and syncing with your own server. Importing a key can save its passphrase too, and **Forget saved passphrase** in the key's menu removes it.
- A key's menu can show its public key as a QR code, install it on a saved host in one step (adding it to `~/.ssh/authorized_keys` only if it isn't there, and making the folder and file if needed), and export the private key, after a warning, optionally locked with a new passphrase.
- The Keys page no longer says private keys stay on this device. They are kept encrypted, and with sync on they go to your other devices in the vault unless you keep a key on this device only.
- Setting up a vault now says plainly, on both the passphrase and the recovery code steps, that losing both means the data in the vault is gone for good.
- The join code for adding a device is shown full screen over a dimmed background, counts down from 60 seconds and closes by itself, and closes at once if you switch apps. Copy it as text and paste it on the new device with **Use a join code instead** to join without typing the passphrase. Scanning it with a camera isn't available yet.
- The command-line tool can list and remove devices (`promptly devices list`, `promptly devices remove`, with `--rekey` to re-key too) and re-key the vault (`promptly rotate-dek`). It also keeps anything marked "this device only" to itself.
- Sync is sturdier. A file from another device that can't be read yet (still copying, not downloaded from iCloud, or damaged) no longer holds up everything after it: the rest applies, and that one is read again each time until it comes through, so nothing is lost. Promptly syncs when you come back to the app, and pulling the Hosts list or the sync screen down syncs straight away. After a failure it waits longer between tries, up to an hour, and Sync now starts over. If the vault's passphrase was changed on another device, its folder was deleted, or it was changed by a newer Promptly, sync pauses and the sync screen says what to do, including setting the vault up again from this device. A new vault file never overwrites one already in the folder.
- Files on a phone: upload files from the phone (several at once) into the folder you have open, download a file to save it or send it on from the share sheet, and open a file in another app. Every transfer shows its progress and can be stopped, on computers too.
- The keyboard bar is yours to arrange: *Settings, Keyboard bar* picks the keys and their order, with F1 to F12, Insert and more symbols to add. Tap Ctrl or Alt twice (or hold it) to lock it on. Hold an arrow key and slide to keep moving. Ctrl or Alt with an arrow, Home, End or the page keys now sends what programs expect, so Ctrl+Left jumps back a word.
- A new user guide covers installing Promptly and every feature, step by step, and **User guide** in Help now opens it.
- Saved passwords, private keys and the key to your sync vault are now encrypted on your device, with a key kept in the system's secure storage (Keychain, Android Keystore, Windows Credential Manager or the Linux keyring). On a Linux computer with no keyring they stay as owner-only files, and Settings says so. Linux builds now need libsecret. Passwords and keys saved by 1.0.0 or 1.0.1 aren't carried over: type the passwords again and re-import the keys.
- Everything else Promptly keeps on your device (hosts, groups, keys, snippets, settings) is now encrypted too, with the same key. On a Linux computer with no keyring it stays unencrypted, and Settings says so; installing a keyring encrypts it the next time Promptly starts. The `promptly` command-line tool's own copy is encrypted as well, so it opens only with the vault's passphrase or recovery code.
- The *Remove device* message and the privacy policy now say that removing a device or changing the passphrase does not lock out a device that has already joined. For a lost one, cut off its access to the vault's storage and change the passwords and keys it had.
- Windows has an installer. It installs for you alone, with no administrator prompt, and adds Promptly to the Start menu and to Settings, Apps for uninstalling. The zip is still there for anyone who prefers it.
- Promptly can tell you about new versions. Press *Check* on the About page, or turn on *Check for updates automatically* in Settings to have it look once a day (off by default). On Windows, when installed with the installer, *Update and restart* installs the new version and opens it again; elsewhere it opens the download page.
- Search highlights the match it is on in solid yellow, with the other matches in a softer yellow, so the current one is easy to spot. Searching for text that repeats inside itself, such as "22" in "222", no longer shows "0 of 1" or a half-highlighted match.
- Hosts have a *None* authentication option for servers that let you in without a password or key, such as Tailscale SSH. *Ask each time* now goes straight in on those servers too, instead of prompting.
- The mouse works in full-screen programs that ask for it, such as vim with `mouse=a`, tmux and htop: clicks, drags and the wheel go to the program. Hold Shift to select text or scroll as before.
- Sync no longer loses changes when a synced folder delivers files out of order, or when a device leaves the vault and joins again. Removing a device waits until all of its changes have arrived, and changing the vault passphrase can no longer leave the folder without its key file.
- Cancelling an SSH connection really stops it. Checking a new server's fingerprint has no time limit, a reconnect is no longer undone by the old connection closing late, and Stop on automatic reconnect stays stopped.
- The text editor keeps typing done while a save is in progress, and Android's Back button asks before throwing edits away.
- A host with "remember password" off saves properly, and a host in a group can leave User blank to use the group's.
- Imported PuTTY and PEM keys keep their passphrase. CSV passwords keep their spaces. Jump hosts from `~/.ssh/config` that Promptly cannot follow are reported instead of being skipped silently.
- On a phone keyboard, backspace erases a whole emoji and keeps working on a command recalled from history. A big paste no longer freezes the app while a program is busy.
- File permissions keep their special bits, Windows paths rename and navigate in the right folder, port forward rows stay in place after one is removed, and exported keys with the same name no longer overwrite each other.
- On desktop, the menu bar is slimmer and its menus open below it instead of over it, rows are more compact, and shortcuts no longer touch the menu's right edge. The nine Tab entries moved into a View, Go to tab submenu. The Help page's shortcut list no longer runs keys into their descriptions, and on a phone the host editor picks how to sign in from a list instead of buttons squeezed so tight their words broke. Session text has a small margin on the left instead of touching the edge.

## 1.0.1

- Promptly for Mac: a free `.dmg` for Apple silicon and Intel Macs. It is not signed by Apple yet, so the first launch needs one trip to System Settings, then Privacy & Security, then *Open Anyway*.

## 1.0.0

The first release: everything from the four milestones.

- A terminal that feels right: smooth scrolling, true colour, themes with live previews, selection and copy, scrollback search, links you can open.
- SSH with the lot: passwords, keys, the agent (on Windows, the OpenSSH agent or Pageant), keyboard-interactive logins, host key checks you cannot miss, automatic reconnect, jump hosts, port forwards (local, remote, SOCKS), tmux-backed persistent sessions, startup commands and environment variables, agent forwarding.
- Hosts, groups, keys and snippets, with favourites, recents, and a dot that says which hosts are up.
- Snippets with `{{variables}}`, run in a session or on many hosts at once.
- A file browser over the session's own connection, with uploads, downloads, permissions and editing text files in place; two panes on desktop.
- Free sync: an encrypted vault in a folder you already sync, or on a server over SFTP. No account, no servers.
- Imports from `~/.ssh/config`, from a CSV such as the one Termius exports, PuTTY `.ppk` keys, and themes from iTerm2, Windows Terminal, Alacritty and base16.
- Desktop: tabs, split panes, a hosts panel, a menu bar and a command palette. Phone: a keyboard bar with Esc, Tab, sticky Ctrl and Alt and arrows.
- A welcome tour, in-app help, and an accessibility pass: labels for screen readers, large text, reduced motion.
