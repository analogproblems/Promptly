# Bundled fonts

**JetBrains Mono** (Regular, Medium, SemiBold, Bold, Italic), static TrueType builds
as served by Google Fonts. Copyright 2020 The JetBrains Mono Project Authors.
Licensed under the SIL Open Font License, Version 1.1; see `OFL.txt` in this folder.

The font is used for the terminal and for anything that should read like the
terminal (host labels, hostnames, snippets, fingerprints). Nerd Font symbol
fallback is added in milestone 1.
