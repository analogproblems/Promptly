# Security

Promptly holds SSH keys and passwords, so security reports are welcome and
taken seriously.

## Reporting a problem

Please report it privately, not in a public issue: open the repository's
**Security** tab and choose **Report a vulnerability**. Only the maintainer
sees the report. Say what you found, how to reproduce it, and which version
and platform you used.

You should hear back within a week. Once a fix is out, the report is
published with credit to you, unless you would rather stay anonymous.

## Supported versions

Fixes go into the newest release. Please update before reporting.
